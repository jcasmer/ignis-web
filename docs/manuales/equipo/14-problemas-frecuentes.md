# 14. Problemas frecuentes

| Síntoma                                                | Causa probable                                                           | Qué hacer                                                                                                                                                           |
| ------------------------------------------------------ | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| El asistente no responde                               | Sin crédito, sin precio del modelo, worker apagado o clave de IA ausente | Revisa [Créditos](04-pestana-creditos.md), [Precios de IA](12-apartados-generales.md#precios-de-ia) y que el worker corra; mira la **Cola de trabajos** en Resumen. |
| La **Cola** muestra trabajos muertos o atascados       | El worker no corre o un paso falla siempre                               | Reinicia el worker y revisa sus registros.                                                                                                                          |
| Un documento queda en **Indexando** o **Falló**        | Worker apagado o servicio de significado (Ollama) caído                  | Arranca el worker/Ollama y usa **Reintentar** ([Conocimiento](09-pestana-conocimiento.md)).                                                                         |
| Búsqueda «solo por palabras»                           | Ollama no respondió o los documentos se indexaron con otro modelo        | Levanta Ollama y pulsa **Reindexar todo**.                                                                                                                          |
| El asistente «inventa» datos                           | Corte de relevancia muy bajo o falta información                         | Sube la **Similitud mínima** y corre la evaluación.                                                                                                                 |
| No se puede activar reranker/reescritura               | No hay proveedor de IA en la plataforma                                  | Configura la clave del proveedor.                                                                                                                                   |
| «Tu plan no incluye…»                                  | Módulo apagado                                                           | Actívalo en [Plan](02-pestana-plan.md).                                                                                                                             |
| «Llegaste al límite…»                                  | Límite del plan                                                          | Sube el límite en Plan.                                                                                                                                             |
| Una automatización **Falló** por plantilla no aprobada | Meta aún no aprueba                                                      | **Actualizar estados** y luego **Reintentar** ([Automatizaciones](10-pestana-automatizaciones.md)).                                                                 |
| Falló por «correo del negocio aún no configurado»      | Falta la pestaña **Correo**                                              | Configura el correo ([Correo](05-pestana-correo.md)).                                                                                                               |
| «Meta no aceptó el token de acceso»                    | Token vencido                                                            | Pegar un token permanente en **Canales**.                                                                                                                           |
| Un conector da error de autorización                   | Credencial vencida o mal pegada; OAuth sin renovar                       | Revisa el conector ([Conectores](08-pestana-conectores.md)).                                                                                                        |
| Un cliente perdió su segundo factor                    | Perdió el teléfono                                                       | Usa sus códigos de recuperación; si no los tiene, no hay atajo desde el panel del cliente: se maneja con el equipo según [Seguridad](03-pestana-seguridad.md).      |
| Una persona del equipo no puede ingresar               | Cuenta desactivada o sin segundo factor                                  | Revisa **Equipo de Ignis**: **Activar** o **Quitar segundo factor**.                                                                                                |

Si nada de esto explica el problema, mira la **bitácora de ejecuciones** del cliente y los registros del servidor; los mensajes de error de la plataforma están en español y dicen qué falló y dónde.
